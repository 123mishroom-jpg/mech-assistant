# Clarify Skill — 机械工程问题澄清分析

## 目标

在给出最终答案之前，对用户的机械工程问题进行**结构化澄清分析**，确保回答覆盖问题的核心要点、不遗漏关键维度、并在信息不足时做出合理假设。

## 核心流程（三步澄清法）

### 第一步：问题拆解

将用户问题拆解为以下维度：

1. **核心概念**：问题涉及哪些机械工程核心概念？（如应力、应变、疲劳、公差等）
2. **所属领域**：属于哪个子领域？
   - 理论力学 / 材料力学 / 结构力学
   - 机械原理 / 机械设计
   - 制造工艺 / 材料科学
   - 液压与气动 / 热力学
   - 工程制图 / 公差配合
3. **问题类型**：
   - 概念解释型（"什么是..."）
   - 计算分析型（"如何计算..."）
   - 方案比较型（"A和B哪个更好..."）
   - 故障诊断型（"为什么会出现..."）
   - 设计指导型（"如何设计..."）

### 第二步：信息完整性检查

检查回答该问题是否需要以下信息，若缺失则**在回答中明确说明假设条件**：

| 检查项 | 说明 |
|--------|------|
| 工况条件 | 载荷、温度、速度、环境等 |
| 材料信息 | 材料类型、力学性能参数 |
| 几何参数 | 尺寸、形状、约束条件 |
| 精度要求 | 公差等级、表面粗糙度 |
| 标准规范 | 是否需要引用国标/ISO/ASME |

**规则**：
- 如果缺失关键信息，不要反问用户，而是**列出合理假设**并基于假设作答
- 在回答开头用 `> 假设条件：...` 标注
- 如果问题本身足够清晰，跳过此步

### 第三步：多角度分析

根据问题类型，从以下角度中选择相关维度展开分析：

| 分析角度 | 适用场景 |
|----------|----------|
| **力学分析** | 受力、变形、强度、刚度、稳定性 |
| **材料角度** | 选材依据、热处理、失效模式 |
| **工艺角度** | 加工方法、装配工艺、成本考量 |
| **标准规范** | 相关国标、行业标准、设计规范 |
| **实际应用** | 典型工程案例、常见误区 |
| **对比分析** | 不同方案的优劣对比 |

## 回答结构模板

完成澄清分析后，按以下结构组织回答：

```
## 核心结论
（一句话给出直接答案）

## 原理分析
（分点解释原理，涉及公式用 LaTeX）

## 关键要点
（3-5 个要点，覆盖多角度分析的结果）

## 注意事项 / 常见误区
（如有）

## 延伸思考
（如有相关的进阶问题或应用场景）
```

## 示例

**用户问题**：齿轮传动比怎么计算？

**Clarify 分析过程**（内部执行，不展示给用户）：
1. 拆解：核心概念=齿轮传动比，领域=机械原理，类型=概念解释+计算
2. 信息检查：未指定齿轮类型（直齿/斜齿/锥齿），未指定是单级还是多级 → 假设单级直齿圆柱齿轮
3. 多角度：力学（传动比公式）、应用（选型考虑）、标准（模数系列）

**最终回答**：
```
## 核心结论
齿轮传动比 i = 从动轮齿数 z₂ / 主动轮齿数 z₁ = 主动轮转速 n₁ / 从动轮转速 n₂

## 原理分析
...（详细公式推导）

## 关键要点
1. 传动比与模数无关，只取决于齿数比
2. 多级传动时，总传动比 = 各级传动比之积
3. 实际选型需考虑标准模数系列（GB/T 1357）

## 注意事项
- 传动比过大时（i > 7），单级齿轮传动效率下降，建议采用多级传动
...
```

## 使用场景

- 用户提出模糊问题时（如"这个零件怎么设计"）
- 问题涉及多个专业交叉时
- 需要给出工程建议而非纯理论回答时
- 问题缺少关键参数时

## 不使用场景

- 简单的事实查询（如"1英寸等于多少毫米"）
- 用户已提供完整参数和明确要求的计算题
- 闲聊或非机械工程相关问题
